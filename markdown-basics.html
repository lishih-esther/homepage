📄 Markdown（.md）寫作格式教學

這個頁面介紹 Markdown 的基本語法、使用方式與範例。

1️⃣ 標題（Headings）

# H1 標題
## H2 標題
### H3 標題

2️⃣ 文字樣式

**粗體**
*斜體*
~~刪除線~~
`程式碼`

粗體、斜體、刪除線、程式碼

3️⃣ 清單

- 項目一
- 項目二
  - 子項目
  • 項目一
  • 項目二
    • 子項目

4️⃣ 連結與圖片

📌 基本語法

[連結文字](https://example.com)
![圖片說明](image.jpg)

📖 說明

  • 連結：使用 [文字](網址) 的格式
  • 圖片：在連結前加上 !，變成 ![說明](圖片網址)
  • 圖片的「說明文字」會在圖片無法顯示時出現（alt text）

✅ 範例

[Google](https://www.google.com)

![範例圖片](https://via.placeholder.com/150)

🔗 連結示範： Google

🖼️ 圖片示範：

⚙️ 進階用法

[Google](https://www.google.com "滑鼠提示文字")

當滑鼠移到連結上時，會顯示提示文字（title）。

📌 小技巧

  • 圖片可以使用網路圖片（URL）或本地檔案
  • 如果圖片太大，可以在 HTML 中用 <img> 控制大小
  • Markdown 本身不支援圖片大小設定，需要搭配 HTML
